## 무엇을 할 수 있나요

- 질문을 하나 넣으면 **3개의 AI가 2바퀴 토론**한 뒤, 사회자(클로드)가 **최종 답**을 정리해 줍니다.
- "토론 과정 보기"를 누르면 각 AI의 답변과 서로에 대한 지적을 단계별로 볼 수 있어요.
- 화면 오른쪽 **미리보기 패널**에 결과물(기획안)이 실시간으로 만들어지고, "이 부분 고쳐줘"라고 하면 바로 다듬어 줍니다.
- 지난 대화가 저장되어 왼쪽 목록에서 다시 열 수 있어요.
- **비밀번호 로그인**이 있어 나만 사용할 수 있습니다.
- 핸드폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 실행됩니다.

## 처음이라면: 데모로 먼저 구경하기

API 키가 아직 없어도 괜찮아요. **데모(mock) 모드**로 실제 화면 흐름을 그대로 체험할 수 있습니다.

```bash
./run-dev.sh
```

- 위 명령을 실행하면 자동으로 데모 모드로 켜집니다. (backend/.env 가 없을 때)
- 브라우저에서 **http://localhost:5173** 로 접속하세요.
- 로그인 비밀번호는 `test` 입니다.
- 질문을 넣으면 진짜 AI 대신 예시 답변으로 전체 흐름이 보여집니다.

> 실제 AI 답변을 받으려면 [AI 키 넣기](#ai-키-넣기-진짜로-쓰려면) 를 따라 하세요.

## 내 컴퓨터에서 실행하기

### 준비물
- **Python 3.9 이상** (터미널에서 `python3 --version` 으로 확인)
- **Node.js 18 이상** + **pnpm** (또는 npm)

### 실행
프로젝트 폴더에서 딱 한 줄이면 백엔드와 프론트엔드가 함께 켜집니다.

```bash
./run-dev.sh
```

- 처음 실행하면 필요한 것들을 자동으로 설치하느라 조금 걸립니다.
- 완료되면 **http://localhost:5173** 로 접속하세요.
- 끄려면 그 터미널 창에서 **Ctrl + C**.

## AI 키 넣기 (진짜로 쓰려면)

진짜 AI 답변을 받으려면 각 회사의 API 키가 필요합니다. (키 3개 중 있는 것만 넣어도 됩니다 — 나머지 AI는 자동으로 빠집니다.)

1. `backend` 폴더 안의 예시 파일을 복사해 `.env` 를 만듭니다.

   ```bash
   cd backend
   cp .env.example .env
   ```

2. `backend/.env` 파일을 열어 값을 채웁니다.

   ```env
   LOGIN_PASSWORD=나만_아는_비밀번호
   SESSION_SECRET=아무거나_길고_임의의_문자열
   ANTHROPIC_API_KEY=sk-ant-...    # 클로드 (https://console.anthropic.com)
   OPENAI_API_KEY=sk-...           # 챗지피티 (https://platform.openai.com)
   GEMINI_API_KEY=...              # 제미나이 (https://aistudio.google.com/apikey)
   ```

3. 다시 실행하면 이제 진짜 AI로 토론합니다.

   ```bash
   cd ..
   ./run-dev.sh
   ```

> 🔒 **키는 절대 코드나 깃에 들어가지 않습니다.** `.env` 파일은 `.gitignore` 로 제외되어 있어요. 오직 환경변수로만 읽습니다.

## 클라우드에 올리기 (Railway) — 아주 쉽게

인터넷만 있으면 어디서든 접속되게, 무료로 시작할 수 있는 **Railway** 에 올리는 방법입니다.
컴퓨터를 잘 몰라도 순서대로만 따라 하면 됩니다.

### 1) 준비
- 이 프로젝트 폴더(`onesis`)를 **GitHub** 에 올려두세요. (GitHub 계정 필요)
- **Railway** 계정을 만드세요 → https://railway.app (GitHub 로 로그인하면 편해요)

### 2) 새 프로젝트 만들기
1. Railway 에서 **New Project** 클릭
2. **Deploy from GitHub repo** 선택 → 방금 올린 `onesis` 저장소 선택
3. Railway 가 폴더 안의 `Dockerfile` 을 자동으로 찾아 빌드를 시작합니다. (몇 분 걸려요)

### 3) 비밀번호와 AI 키 넣기 (환경변수)
1. 프로젝트 화면에서 서비스를 클릭 → **Variables** 탭으로 이동
2. 아래 값들을 하나씩 추가합니다. (New Variable)

   | 이름 | 값 |
   |------|-----|
   | `LOGIN_PASSWORD` | 나만 아는 비밀번호 |
   | `SESSION_SECRET` | 아무거나 길고 임의의 문자열 |
   | `ANTHROPIC_API_KEY` | 클로드 키 |
   | `OPENAI_API_KEY` | 챗지피티 키 |
   | `GEMINI_API_KEY` | 제미나이 키 |
   | `DATA_DIR` | `/data` |

### 4) 대화 기록이 사라지지 않게 (영구 저장 공간)
1. 서비스에서 **Variables/Settings** 근처의 **＋ (Volume)** 또는 우클릭 → **Add Volume**
2. **Mount path** 를 `/data` 로 지정하세요. (위에서 넣은 `DATA_DIR` 값과 같아야 합니다)
3. 이렇게 하면 서버가 재시작돼도 지난 대화가 그대로 남습니다.

### 5) 접속 주소 만들기
1. 서비스 → **Settings** → **Networking** → **Generate Domain** 클릭
2. `https://onesis-production-xxxx.up.railway.app` 같은 주소가 생깁니다.
3. 그 주소로 접속 → 비밀번호를 넣으면 어디서든 사용할 수 있어요!

> **Render** 를 쓰고 싶다면? 방법은 거의 같습니다. New → Web Service → 이 깃 저장소 선택 → Docker 로 빌드 → 환경변수(위 표) 입력 → Disk(영구 저장소)를 `/data` 에 연결하면 됩니다.

## 핸드폰 홈 화면에 앱으로 추가하기

배포된 주소(또는 같은 와이파이의 컴퓨터 주소)를 핸드폰 브라우저로 연 다음:

- **아이폰 (Safari)**: 아래쪽 **공유 버튼** (⬆️ 네모) → **"홈 화면에 추가"**
- **안드로이드 (Chrome)**: 오른쪽 위 **⋮ 메뉴** → **"홈 화면에 추가"** (또는 "앱 설치")

그러면 홈 화면에 **오네시스 아이콘**이 생기고, 눌러서 일반 앱처럼 전체화면으로 실행됩니다.

<br>

## 모델(AI 종류) 바꾸기

사용하는 모델 이름은 **`backend/app/config.py`** 한 곳에 모여 있습니다. 더 저렴하거나 빠른 모델로 언제든 바꿀 수 있어요.

```python
ANTHROPIC_MODEL = "claude-opus-5"      # 예: claude-sonnet-4-5 로 바꾸면 더 저렴/빠름
OPENAI_MODEL    = "gpt-4o"             # 예: gpt-4o-mini
GEMINI_MODEL    = "gemini-2.0-flash"   # 예: gemini-2.0-flash-lite
```

환경변수(`ANTHROPIC_MODEL` 등)로 덮어쓸 수도 있어, 코드를 고치지 않고 Railway 변수만 바꿔도 됩니다.

## 자주 묻는 것

**Q. 한 AI가 오류를 내면 멈추나요?**
아니요. 오류난 AI는 자동으로 건너뛰고 나머지 AI로 계속 토론합니다.

**Q. 토론은 몇 바퀴 도나요?**
항상 **2바퀴 고정**입니다. (1차 답변 → 토론1 → 답변 수정 → 토론2 → 사회자 최종 정리)

**Q. "이대로 제작하기" 버튼은 뭔가요?**
미리보기의 기획안을 그대로 **클로드 코드**에게 넘겨 실제로 프로그램을 만들게 하는 버튼입니다.
누르면 확인창이 뜨고, 승인하면 `~/onesis-builds/날짜_제목/` 전용 폴더가 새로 생겨 **그 안에서만** 작업합니다.
진행 로그가 실시간으로 보이고, 끝나면 만들어진 파일 목록과 함께 **결과물을 zip으로 다운로드**할 수 있어요.
(클라우드 배포 시 서버에 클로드 코드가 자동 설치되며, 서버의 `ANTHROPIC_API_KEY` 를 사용합니다. `backend/.env` 가 없으면 데모 모드로 시뮬레이션합니다.)

**Q. 비용이 걱정돼요.**
질문 1개당 AI를 여러 번 호출합니다(약 13번). 자주 쓰면 요금이 나올 수 있으니,
`config.py` 에서 더 저렴한 모델로 바꾸는 것을 권장합니다.

### 오프라인 모드 (여행 중 인터넷이 없을 때)
- 지난 대화와 기획안은 기기에 저장되어 **인터넷 없이도 열람**할 수 있어요.
- 오프라인에서 미리보기(기획안)를 직접 편집하면 기기에 임시 저장됐다가, **연결되면 자동으로 서버와 동기화**됩니다.
- **예약 질문함**: 오프라인에서 질문을 쓰면 저장해 뒀다가, 인터넷이 연결되는 순간 **자동으로 토론이 시작**됩니다. 화면에 "대기 중인 질문 N개"가 표시돼요.
- PWA라서 앱 자체도 오프라인에서 열립니다(홈 화면에 추가한 경우).
